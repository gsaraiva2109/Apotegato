# Instruções para agentes

- Leia o `CONTRIBUTING.md`: convenções de código, pastas, branches e arte de terceiros.
- **Nome de branch nunca contém "claude"** (nem variações). Use os prefixos do `CONTRIBUTING.md` (`feat/`, `fix/`, ...) com nomes descritivos do trabalho. Isso vale para qualquer agente.
- Commits e PRs no nome do usuário, sem co-autor nem rodapé de ferramenta; mensagens e descrições em português.
- Código, pastas, arquivos e nós em inglês; comentários, docs e textos do jogo em português.
- Arte de terceiros fica só no repositório privado `gsaraiva2109/ApotegatoAssets` (baixada por `tools/fetch_assets.sh`); nunca a versione aqui.
